A project file is JSON (compose.json) or YAML (compose.yaml) in the shape of the Compose specification. Strings may use ${VAR} and the other Compose variable forms. A key that is not listed here is an error: Anastasis never runs a file differently than it is written. Durations are Compose durations such as 5s or 1m30s.

Top level

KeyMeaning
nameProject name. COMPOSE_PROJECT_NAME wins over it; without either, the directory name is used. Lowercase letters, digits, - and _.
servicesThe services, by name.
volumesNamed volumes the services use; see named volumes.
networksAccepted; every project gets one network, so only default may be named.
versionAccepted and ignored, as in Compose.
x-…Any key starting with x- is ignored, so it can hold shared values.

Named volumes

KeyMeaning
nameThe volume's real name. Default: project_key.
externaltrue: the volume exists already, is never deleted, and may be shared between projects. Its name defaults to the key.
driverOnly local.
labelsAccepted and ignored.

Service keys

KeyMeaning
imageRequired. Use the fully qualified name, with the registry.
commandA string or a list.
entrypointA string or a list.
environmentA mapping or a list of KEY=value. A bare KEY takes its value from your environment, or is left out.
env_fileA path, a list of paths, or a list of {"path": …, "required": false} (path, required). Files load in order; environment wins.
volumesMounts; see volumes.
healthcheckSee healthcheck.
labelsA mapping or a list.
userUser inside the container.
working_dirWorking directory inside the container.
stop_signalSignal that stops a replica.
stop_grace_periodTime between that signal and a kill. Default 10s.
cap_addPassed to Podman as written.
cap_dropPassed to Podman as written.
read_onlyRead-only root filesystem.
deploySee deploy.
portsPublishes ports directly; see ports. Only for a single replica.
networksOnly default.
depends_onAccepted and ignored: Anastasis retries until dependencies are up. The names must still be services of the project.
restartAccepted; Anastasis keeps every service running. "no" and on-failure are refused.
container_nameAccepted and ignored: Anastasis names replicas itself.
nameAccepted and ignored.
x-anastasisSee x-anastasis.

healthcheck

KeyMeaning
testA list such as ["CMD", "wget", "-qO-", "http://localhost:8080/health"], or a string, which runs in a shell.
intervalTime between checks.
timeoutA check that takes longer fails.
start_periodFailures during this time after start do not count.
retriesFailures in a row before a replica is unhealthy and replaced.
disableTurn off the image's own healthcheck.
start_intervalAccepted and ignored.

A replica only gets traffic once its healthcheck passes. Without a healthcheck it counts as ready when it starts.

ports

Short form [[host_ip:]published:]target[/protocol], such as "8080:80", or the long form below. A service with ports runs one replica and updates with stop-first; to scale, use expose. Port ranges are refused.

KeyMeaning
targetContainer port, required.
publishedHost port.
host_ipHost address to bind.
protocoltcp (default), udp or sctp.
modeAccepted and ignored.
nameAccepted and ignored.
app_protocolAccepted and ignored.

volumes

Short form [source:]target[:mode]. A source that is a path (./data, /srv/data, ~/data) is a bind mount; any other source is a named volume, which must be declared at the top level. No source makes an anonymous volume, which belongs to one replica and is deleted with it. Relative paths are relative to the project file.

KeyMeaning
typebind, volume or tmpfs.
sourceHost path or volume name. Required for a bind mount.
targetAbsolute path in the container.
read_onlyMount read-only.
bindselinux (z or Z) and create_host_path. propagation and recursive are refused.
volumenocopy and subpath are refused.
tmpfsRefused: tmpfs options are not supported. A plain type: tmpfs works.
consistencyAccepted and ignored.

deploy

KeyMeaning
replicasHow many replicas to run. Default 1. With autoscaling, the starting count.
resourceslimits: cpus (such as "0.5") and memory (such as "256m"). reservations is accepted and ignored.
update_configHow rollouts run; see below.
restart_policyAccepted; condition none and on-failure are refused.
modeOnly replicated.
labelsAccepted and ignored.
endpoint_mode, placement, rollback_configRefused; see refused keys.

update_config

KeyMeaning
parallelismReplicas replaced at a time. Default 1; 0 means all at once.
delayWait between batches.
monitorHow long new replicas must survive. Default 30s.
orderstart-first (default) or stop-first (default with ports, the only order ports allows).
failure_actionpause (default), rollback or continue.
max_failure_ratioRefused unless 0.

x-anastasis

A service-level block for what Compose has no keys for.

KeyMeaning
expose"hostPort:containerPort", such as "8000:8080": the HTTP load balancer on the host port, forwarding to that port of every ready replica.
stickytrue keeps each browser on one replica. Needs expose.
autoscaleSee below.

autoscale

KeyMeaning
maxRequired, at least 1.
minAt least 1; defaults to deploy.replicas. Scaling to zero is not supported.
inflightTarget concurrent requests per replica. Needs expose.
cpuTarget percent of the CPU limit per replica. Needs deploy.resources.limits.cpus.

Set inflight, cpu, or both; the higher replica count wins. A service with ports cannot autoscale.

Refused keys

Anastasis stops with an error on these instead of running something you did not write.

KeyWhy, and what to do instead
buildAnastasis does not build images. Push an image and set image.
network_mode, custom networksEvery project gets one network; services reach each other by name.
restart: "no", restart: on-failureEvery service is kept running. Run one-shot jobs with podman run.
privileged, devices, pidNot supported, along with any service key not listed under service keys.
endpoint_mode, placement, mode: globalSwarm-only: there is one host.
rollback_configUse update_config.failure_action: rollback.
max_failure_ratioNot supported; leave it out or set it to 0.
propagation, recursiveBind propagation options are not supported.
nocopy, subpathVolume options are not supported.
tmpfs optionsUse a plain type: tmpfs mount.
Port rangesPublish each port on its own.
Volume drivers other than localAnastasis uses Podman's local volumes.

Commands

CommandWhat it does
anastasis serveRuns Anastasis: the loop that keeps services at their size, and the API socket the other commands talk to. Usually started by the systemd user unit.
anastasis upRegisters or updates the project and waits, up to 5 minutes, until it converges.
anastasis down projectRemoves the project's containers and network.
anastasis scale project service=n …Sets replica counts until the next up. Refuses autoscaled services.
anastasis status [project]Shows every service, or one project's.
anastasis rollout restart project serviceRolls every replica and pulls the image again.
anastasis versionPrints the version.
